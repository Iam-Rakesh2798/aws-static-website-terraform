# AWS Static Website with Terraform

## Overview

This project demonstrates deployment of a static website on AWS using:

- Terraform
- Amazon S3
- Amazon CloudFront
- GitHub Actions

## Architecture

GitHub → GitHub Actions → S3 → CloudFront

## Features

- Infrastructure as Code (Terraform)
- Static Website Hosting
- CDN using CloudFront
- CI/CD using GitHub Actions
